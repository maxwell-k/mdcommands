# minutesspent

> [!TIP]
> The command below assumes you have compatible versions of Node.js and npm,
> plus write access to your npm prefix directory — `npm config get prefix`.

Command to install from this directory:

    npm install --global .

## Example usage

Command:

    echo I spent 120 minutes. | minutesspent

Output:

    0200
